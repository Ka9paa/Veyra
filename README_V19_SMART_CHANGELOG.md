# VEYRA STUDIO V19 — SMART CHANGELOG

V19 makes Veyra explain its work like a real software engineer.

After each build/edit Veyra now:
- Gives a specific explanation of what changed
- Shows a dedicated "Files changed" section
- Lists the exact file name
- Labels each file as Updated / Created / Reviewed, etc.
- Explains the concrete change inside each file
- Suggests useful next steps
- Avoids inventing filenames that are not part of the current project

The live preview, OpenAI backend, local fallback, QA, and prior V18 UI scale changes remain intact.
